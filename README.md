# Diplom_2

 Stellar Burgers API Tests
Проект автоматизированного тестирования API для сервиса Stellar Burgers.

# Библиотеки и фреймворки:
 - pytest 7.4.0 - основной фреймворк для написания и запуска тестов
 - requests 2.31.0 - для выполнения HTTP-запросов к API
 - allure-pytest 2.13.2 - для создания подробных отчетов о тестировании
 - allure-python-commons 2.13.2 - общие утилиты для интеграции Allure

Проект включает 3 группы тестов, охватывающих основные сценарии API:

1. Тесты создания пользователя (test_create_user.py)
 - создать уникального пользователя;
 - создать пользователя, который уже зарегистрирован;
 - создать пользователя и не заполнить одно из обязательных полей.

2. Тесты авторизации пользователя (test_login_user.py)
 - вход под существующим пользователем;
 - вход с неверным логином и паролем

3. Тесты создания заказа (test_create_order.py)
 - с авторизацией;
 - без авторизации;
 - с ингредиентами;
 - без ингредиентов;
 - с неверным хешем ингредиентов.

# Особенности реализации
1. Клиент для работы с API (api_client.py)
 - Инкапсуляция логики HTTP-запросов
 - Автоматическое управление токенами авторизации
 - Унифицированная обработка ошибок
 - Поддержка всех требуемых эндпоинтов

2. Фикстуры (conftest.py)
 - Подготовка тестовых данных
 - Автоматическая регистрация и удаление пользователей
 - Получение актуальных ингредиентов
 - Изоляция тестовых сценариев

3. Генерация тестовых данных
 - Уникальные email для каждого теста
 - Случайные имена пользователей
 - Динамический подбор ингредиентов
 - Валидные и невалидные данные для негативных тестов

4. Отчетность
 - Подробные шаги выполнения в Allure
 - Уровни серьезности тестов (Blocker, Critical, Normal)
 - Группировка тестов по функциональностям
- Визуализация результатов выполнения

# Запуск тестов
 Установка зависимостей
 pip install -r requirements.txt

# Запуск всех тестов
 pytest -v 

# Запуск с генерацией Allure-отчетов
 pytest --alluredir=allure-results -v
